# J-Link package folder

Put the SEGGER J-Link software package for Linux, the 64-bit x86 Debian file (`JLink_Linux_<version>_x86_64.deb`), in this folder before you build the board Dev Container. Download it yourself from SEGGER and accept its licence there; the container build never downloads it. Git ignores every other file in this folder.

The [board guide](../../../docs/board-jlink-usbipd.md#3-the-board-dev-container) explains the rest.
